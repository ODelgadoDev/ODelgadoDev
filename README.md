## 🧠 Sobre mí

¡Hola! Soy Orlando, estudiante de Ingeniería en Desarrollo de Software en la **Universidad Tecnológica de Chihuahua (UTCH)**.

Me apasiona construir soluciones que vayan más allá de las tareas académicas. Disfruto trabajar tanto en frontend como en backend, diseñar bases de datos, desarrollar APIs y comprender cómo se conectan los componentes de un sistema.

Durante mi estadía profesional participé en el desarrollo de un **sistema administrativo ERP para TengoClima**, llevando conocimientos de programación a una aplicación empresarial real.

Actualmente sigo ampliando mis conocimientos en arquitectura de software, microservicios, bases de datos, Linux y desarrollo multiplataforma.

> 🐦‍⬛ No me conformo con saber que algo funciona. Quiero entender por qué funciona, cómo está construido y cómo hacerlo mejor.
